# วิธีสร้างตัวติดตั้ง MSI ของ Inkjet Operator

โฟลเดอร์นี้ใช้สร้างไฟล์ติดตั้ง `InkjetOperator.msi` แบบกดทีเดียวจบ

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|------|---------|
| `build.bat` | **ดับเบิลคลิกไฟล์นี้เพื่อสร้าง MSI** (ง่ายที่สุด) |
| `build.ps1` | ตัวสคริปต์จริง (publish + build MSI) |
| `Product.wxs` | ค่าตั้งของตัวติดตั้ง (ชื่อ, เวอร์ชัน, shortcut) |
| `license.rtf` | ข้อความ license ที่โชว์ตอนติดตั้ง |
| `InkjetOperator.msi` | ผลลัพธ์ที่ได้ (เอาไปติดตั้งเครื่องปลายทาง) |

---

## สร้างครั้งแรก / อัพเดทเวอร์ชันใหม่

### วิธีที่ 1 — ดับเบิลคลิก (ง่ายสุด)
ดับเบิลคลิก **`build.bat`** → รอสักครู่ → ได้ไฟล์ `InkjetOperator.msi`
> ใช้เวอร์ชัน default 1.0.0

### วิธีที่ 2 — ระบุเลขเวอร์ชัน (แนะนำตอนอัพเดท)
เปิด PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์:
```powershell
.\build.ps1 1.0.1
```
เปลี่ยน `1.0.1` เป็นเลขที่ต้องการ

---

## ขั้นตอนอัพเดทโปรแกรมให้เครื่องหน้างาน

1. แก้โค้ด / แก้ค่าใน `InkjetOperator/App.config` ให้เรียบร้อย
2. รัน `build.ps1` พร้อม **ขยับเลขเวอร์ชันขึ้น** เช่น `.\build.ps1 1.0.2`
   > สำคัญ: ต้องขยับเลขทุกครั้ง ไม่งั้นลงทับตัวเก่าไม่ได้
3. เอา `InkjetOperator.msi` ตัวใหม่ไปดับเบิลคลิกลงทับเครื่องเดิมได้เลย
   > ระบบถอนตัวเก่าให้อัตโนมัติ (ไม่ต้อง uninstall ก่อน) และค่าตั้งของผู้ใช้ไม่หาย

---

## หมายเหตุสำคัญ

- **MenuMode และค่าตั้งอื่นๆ** อ่านจาก `InkjetOperator/App.config` (ไฟล์ต้นทาง)
  ต้องแก้ที่ไฟล์นี้ก่อน build ทุกครั้ง — แก้ที่ไฟล์ `.dll.config` ในโฟลเดอร์ build จะถูกเขียนทับ
- **UpgradeCode** ใน `Product.wxs` ห้ามเปลี่ยนเด็ดขาด (คือรหัสประจำตัวโปรแกรม
  ที่บอก Windows ว่าตัวใหม่กับตัวเก่าคือโปรแกรมเดียวกัน)
- ตัวติดตั้งฝัง .NET runtime มาด้วย (self-contained) → เครื่องปลายทางไม่ต้องลง .NET ก่อน
  แต่ไฟล์จะใหญ่ (~58 MB) เป็นเรื่องปกติ

---

## ถ้าเครื่องยังไม่มี WiX (ลงครั้งเดียว)

สคริปต์นี้ใช้ WiX v5 ถ้าเครื่องใหม่ยังไม่มี ให้ลงครั้งเดียว:
```powershell
dotnet tool install --global wix --version 5.0.2
wix extension add -g WixToolset.UI.wixext/5.0.2
```
